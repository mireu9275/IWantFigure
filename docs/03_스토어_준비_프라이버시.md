## 3. 스토어 심사 대응

### App Store 리뷰 노트(초안, 영어)

> IWantFigure is a coaching app for Japanese arcade crane games (skill-based prize machines, UFO catchers). The user photographs the machine; the app suggests where to position the claw. There is no real-money gambling, no betting, no in-app wagering and no prizes are awarded by the app (Guideline 5.3 does not apply; crane games in Japan are regulated as amusement machines with prizes under ¥1,000 retail). Camera access is used only to photograph the machine; faces are pixelated on the device before any upload (Guideline 5.1.2 consent is shown on first launch). The 3D view is an interactive model of the machine with the recommended claw position, not a decorative AR placement (4.2.1). Test instructions: enable "mock mode" in Settings to try the full flow without a server.

## 4. 매장에서의 사용 안내(앱 내 촬영 가이드에 반영됨)

- 촬영 가능 여부는 매장 규정을 따른다(GiGO·ラウンドワン 개인 촬영 허용 ★, タイトーステーション 원칙 금지·허가제 ★).
- 사진 1장, 수 초 내 해석. 대기 손님이 있으면 1게임 안에 마친다.
- 다른 손님·점원이 찍히지 않게 하고, 찍혔다면 앱이 자동으로 가린다.
- 특정 매장·기기를 "사기"로 단정하는 표현을 앱·커뮤니티에서 금지(확률기 판정은 '추정').
