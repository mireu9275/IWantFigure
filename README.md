# IWantFigure

일본 게임센터 크레인게임(クレーンゲーム / UFOキャッチャー) 기계를 스마트폰으로 찍으면 AI가 경품 배치 유형을 인식하고 "어디를 노려야 하는지"를 3D로 추천해 주는 iOS/Android 앱 프로젝트.
